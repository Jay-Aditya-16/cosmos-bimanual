Field notes

A world model, not a simulator.

Cosmos3 Nano Sim Bimanual is NVIDIA's action-conditioned world model for a two-arm AgiBot. You give it a starting image, a task prompt, and calibrated controller poses. It generates the next frames of the scene. The controller is the client; the model predicts what the scene looks like as those controllers move.

What to expect

  • This is visual prediction. It does not expose physics state, collision checks, or task success scores.
  • Poses are approximate and live in a calibrated tracking space. They are not robot joint angles.
  • The AgiBot checkpoint supports AgiBot starting scenes. Other robots are not supported by swapping the image.
  • Frames can repeat or drop. Preview frames are not a synchronized action-to-observation benchmark.
  • Prompts guide appearance and context. Arm motion comes from the controller, not the text.

Controls

Pointer: drag, click, scroll. Hands: webcam wrist tracking and pinch grips. Gamepad: two sticks, triggers, D-pad. Keyboard: 1/2 arm, G grip, Space pause, R reset, C recenter, P save frame.

Your API key never reaches GitHub or this page's host. The browser sends it only to Reactor's token endpoint, then holds the resulting scoped JWT for the session. GitHub Pages serves the HTML and does not see the key.
